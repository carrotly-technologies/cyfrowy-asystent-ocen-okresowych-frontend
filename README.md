# Cyfrowy Asystent Ocen Okresowych

Ocena okresowa w służbie cywilnej bez papieru — zgodna z prawem, z myślą o rozwoju ludzi.
HackNation 2026 · zadanie Kancelarii Prezesa Rady Ministrów · zespół Carrotly.

- 🎬 **Film (60 s):** https://youtu.be/wk0RPdygtS0
- 🌐 **Prototyp:** https://cyfrowy.rabbithole.carrotly.tech — na ekranie logowania wybierz rolę jednym kliknięciem (dane fikcyjne)
- 💻 **Kod:** [backend](https://github.com/carrotly-technologies/cyfrowy-asystent-ocen-okresowych-backend) · [frontend](https://github.com/carrotly-technologies/cyfrowy-asystent-ocen-okresowych-frontend)

**Co robi:** prowadzi cały proces oceny okresowej (arkusz A/B/C i kryteria → rozmowy → obserwacje → ocena z kontrolą formalną → podpis → zapoznanie → sprzeciw), sam liczy terminy z przepisów i przypomina o nich, wspiera przełożonego wirtualnym asystentem HR (sygnały przeciążenia, podpowiedzi do rozwoju) i asystentem AI odpowiadającym zawsze ze źródłem w przepisach.

**Wdrożenie:** otwarty kod (EUPL-1.2), bez kosztów licencji, uruchomienie na serwerze urzędu.
